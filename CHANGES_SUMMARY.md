## 🔍 Key Integration Points

### Authentication Flow
1. User sets `SAMBANOVA_API_KEY` environment variable OR
2. User runs `/login sambanova` and stores in `auth.json` OR
3. User manually edits `~/.pi/agent/auth.json` with key

### Model Resolution
1. `findEnvKeys()` in env-api-keys.ts → finds SAMBANOVA_API_KEY
2. Provider factory creates SambaNova provider with models
3. CLI resolves `--model sambanova-large` or `/model` selection
4. Requests sent to `https://api.sambanovasystems.com/v1` with Bearer auth

### Cost Tracking
- Input tokens tracked at configured rate (default $0.5/$1.5 per 1M)
- Cost display in footer during session
- Cost stored in session data for analytics
