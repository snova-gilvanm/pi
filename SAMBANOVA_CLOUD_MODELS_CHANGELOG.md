# SambaNova Cloud Models Integration - Changelog

## Version 1.1: Complete SambaNova Cloud Model Integration

**Date**: 2026-07-22
**Status**: ✅ Complete and tested
**Build**: ✅ Passing

### Overview
Added all 6 official SambaNova Cloud models from https://docs.sambanova.ai/docs/en/models/sambacloud-models to Pi.

### Models Added

#### Production Models (4)
1. **Meta Llama 3.3 70B Instruct**
   - ID: `Meta-Llama-3.3-70B-Instruct`
   - Context: 128K, Reasoning: No, Vision: No
   - Default model (production-ready, balanced)

2. **MiniMax M2.7**
   - ID: `MiniMax-M2.7`
   - Context: 192K (largest), Reasoning: No, Vision: No
   - For large document analysis

3. **OpenAI GPT OSS 120B**
   - ID: `gpt-oss-120b`
   - Context: 128K, Reasoning: Yes, Vision: No
   - For complex logic problems

4. **DeepSeek V3.1**
   - ID: `DeepSeek-V3.1`
   - Context: 128K, Reasoning: Yes, Vision: No
   - Enterprise model with strong reasoning

#### Preview Models (2)
5. **DeepSeek V3.2**
   - ID: `DeepSeek-V3.2`
   - Context: 32K (smallest), Reasoning: Yes, Vision: No
   - Fastest model, experimental

6. **Google Gemma 4 31B Instruct**
   - ID: `gemma-4-31B-it`
   - Context: 128K, Reasoning: No, Vision: Yes ✨
   - Only multimodal model with image support

### Key Features

#### Vision Support
- **Gemma 4 31B** is the only model with image support
- Use for screenshot analysis, diagram interpretation, visual documentation

#### Reasoning Models
- **DeepSeek V3.1**, **DeepSeek V3.2**, **GPT OSS 120B** support extended thinking
- Use for complex logic, mathematical reasoning, detailed problem solving

#### Large Context
- **MiniMax M2.7** supports 192K tokens (largest)
- Designed for analyzing full codebases, long documents
- Other models support 128K (MiniMax leads by 64K)

#### Speed
- **DeepSeek V3.2** is fastest (32K context, optimized)
- **Meta Llama 3.3** is fast and production-ready
- Trade-off: larger context = slower inference

### Migration Guide

For users upgrading from previous version:

#### 1. Rebuild
```bash
npm run build  # Generates new sambanova.json with all 6 models
```

#### 2. Update saved sessions (if any)
Find and replace model IDs:
- `sambanova-large` → use `Meta-Llama-3.3-70B-Instruct`
- `sambanova-medium` → use `DeepSeek-V3.2` or `Meta-Llama-3.3-70B-Instruct`

#### 3. Test models
```bash
export SAMBANOVA_API_KEY="your-key"
./pi-test.sh --model Meta-Llama-3.3-70B-Instruct
./pi-test.sh --model MiniMax-M2.7
./pi-test.sh --model gemma-4-31B-it
```

### Known Limitations

1. **Pricing**: All models show $0 cost (no pricing data in documentation)
   - Update `packages/ai/scripts/generate-models.ts` when pricing available
   
2. **Max Output Tokens**: Estimated as 10% of context window
   - Update in `packages/ai/scripts/generate-models.ts` if different

3. **Image Support**: Only Gemma 4 31B currently marked as supporting images
   - Verify other models don't support images from SambaNova docs

4. **DeepSeek V3.2 Small Context**: 32K is smallest, may be limiting
   - Useful for quick tasks but not large documents
